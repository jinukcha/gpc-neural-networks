# R0C-CP1 — Tower families

```text
task
ROYAL-CAPITAL-FORTIFICATION-CAD-R0C-CP1
— ROUND / SQUARE / POLYGONAL TOWER FAMILIES,
  BOUNDS / ATTACHMENT
  & FOUNDATION SOCKETS
```

This checkpoint introduces three bounded tower-family Producers through the existing project-owned build123d adapter. It owns tower family dimensions, deterministic footprint approximation, semantic solids, exact wall attachment intersections, local socket frames, bounds evidence and flat-reference foundation contact evidence.

It does **not** implement tower/span joins, battlements, playable interiors, roof realization, collision, navigation, Godot import or final semantic surface coverage. Those remain assigned to R0C-CP2, R0C-CP3, WORLD-FIELD/ARCHITECTURE, R0E and R0C-CP4 respectively.
