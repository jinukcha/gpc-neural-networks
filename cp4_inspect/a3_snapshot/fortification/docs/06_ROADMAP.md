```text

```

### CP1 — project-owned provider adapter

- neutral request/result models
- units/frame/tolerance contract
- typed status normalization
- CADProviderReceipt and stored-copy export
- no build123d public type leakage

### CP2 — straight wall-span pilot

- one straight foundation/body/walk/parapet profile
- semantic parts and sockets
- fixed tessellation
- same clean run byte-identical

### CP3 — source coverage and negative gates

- BREP/part → semantic surface → triangle ranges
- invalid input/budget/stale/runtime mismatch gates
- no partial output

### CP4 — R0A closeout

- exact runtime replay
- final full/patch/source equality
- R0A terminal report; R0B starts only by explicit approval
